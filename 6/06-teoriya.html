Инструменты создания изображений

Прежде чем приступить к созданию изображения, необходимо установить требуемые размеры холста. Это можно сделать с помощью протягивания мышью за маркеры, расположенные по углам и бокам холста.

Для того чтобы создавать рисунки в графическом редакторе Paint, необязательно обладать художественными способностями. Изображения можно создать из графических объектов: линий, прямоугольников, треугольников, овалов и др.

Для рисования графических объектов в Paint используются инструменты группы Фигуры панели инструментов.

Линии и большинство фигур рисуются с использованием протягивания. Для линий и контуров фигур можно задавать толщину и выбирать тип. Также можно задавать свойства заливки фигур. Эти свойства задаются перед рисованием с помощью кнопок.

При рисовании фигур цвет линии, цвет заливки и фона определяются с помощью кнопок, расположенных слева от палитры:

  • Цвет 1 — задаёт цвет контура при нажатой левой кнопке мыши или цвет заливки при нажатой правой кнопке мыши;
  • Цвет 2 — задаёт цвет заливки при нажатой левой кнопке мыши или цвет контура при нажатой правой кнопке мыши.

В палитре выбор цвета достаточно ограничен. Для добавления цвета в палитру используется окно Изменить цвета, которое открывается кнопкой.

Для выбора цвета удобно использовать спектр. Вначале выбрать цвет щелчком, а затем настроить его интенсивность, перемещая указатель вдоль цветовой линейки.

💡 Важно понять Если при рисовании линии удерживать клавишу Shift, то получим горизонтальную, вертикальную линии или линию под углом в 45°. При рисовании фигур, имеющих одинаковые размеры по горизонтали и вертикали, также нужно удерживать Shift.

Фигуру с любым количеством сторон можно нарисовать инструментом Многоугольник.

Для закрашивания замкнутых контуров можно использовать инструмент Заливка. При щелчке левой кнопкой мыши заливка выполняется Цветом 1, а при щелчке правой — Цветом 2.

Для рисования произвольных линий с различными эффектами используется набор инструментов Кисти. Порядок работы с инструментами Кисти:

  • сделать выбор в списке инструментов Кисти;
  • определить толщину росчерка кисти (так же, как и толщину линий);
  • выбрать Цвет 1 и Цвет 2.
💡 Полезно знать Если при рисовании возникает ситуация, требующая вернуться к предыдущему этапу работы, кроме кнопки на Панели быстрого доступа можно использовать комбинацию клавиш Ctrl + Z.

Работа с текстом

Часто возникает необходимость дополнить изображение текстом. Для создания текста в графическом редакторе Paint используется инструмент Текст группы Инструменты.

📌 Важно Графические редакторы не предназначены для работы с текстом. Ввод текста в таких программах является дополнительной возможностью.

Порядок работы с инструментом Текст:

  • выбрать инструмент Текст;
  • после щелчка кнопкой мыши на холсте появится прямоугольная область с текстовым курсором;
  • выбрать шрифт, размер и стиль текста;
  • выбрать цвет текста;
  • при необходимости выбрать цвет фона как Цвет 2 и установить непрозрачный фон: Заливка фона;
  • ввести текст в прямоугольную область;
  • завершить ввод текста, выполнив щелчок кнопкой мыши вне прямоугольной области.
⚠️ Внимание Будьте внимательны! По завершении ввода текст преобразуется в изображение и редактированию не подлежит.

Главное

  • Рисунки в Paint создаются из графических объектов: линий, прямоугольников, треугольников, овалов и др.
  • Для рисования фигур используется группа инструментов Фигуры.
  • Клавиша Shift помогает нарисовать ровные линии и фигуры.
  • Фигуру с любым количеством сторон рисует инструмент Многоугольник.
  • Для закрашивания замкнутых контуров используется инструмент Заливка.
  • Для произвольных линий используется набор инструментов Кисти.
  • Текст в Paint создаётся инструментом Текст, но после завершения ввода он становится изображением и не редактируется.
