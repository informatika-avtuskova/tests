Алгоритм и алгоритмические конструкции

В 7-м классе вы познакомились с основами программирования на языке Python. Для решения задач по программированию были выделены основные этапы.

📌 Определение Алгоритм — конечная последовательность точных действий, формальное выполнение которых позволяет получить решение задачи для любого допустимого набора исходных данных.
📌 Определение Исполнитель — человек (группа людей) или техническое устройство, которое способно правильно выполнять команды алгоритмов. Набор команд одного исполнителя называют системой команд исполнителя.
📌 Определение Программа — это алгоритм, записанный на некотором формальном языке — языке программирования.

Все алгоритмы, которые составляет человек, рассчитаны на конкретного исполнителя. Все команды исполнителя делят на группы:

  • команды, которые непосредственно выполняет исполнитель;
  • команды, изменяющие порядок выполнения других команд исполнителя, которые называют командами управления (управляющими конструкциями). К ним относят команды повторение и ветвление.

Любой алгоритм может быть записан с использованием трёх базовых алгоритмических конструкций: следование, повторение и ветвление.

Командами в языке программирования считают:

  • операторы (оператор присваивания, оператор ветвления, оператор цикла и др.);
  • вызовы встроенных и пользовательских вспомогательных алгоритмов (функций).

Этапы решения задачи по программированию

Для решения задач по программированию были выделены основные этапы (пример 1.1):

  • I. Определение исходных данных;
  • II. Определение результатов;
  • III. Составление алгоритма решения задачи;
  • IV. Определение типов данных для переменных;
  • V. Написание программы;
  • VI. Тестирование программы;
  • VII. Анализ результатов.
💡 Важно понять В процессе решения задачи некоторые этапы приходится повторять до тех пор, пока анализ результатов не покажет, что задача решена верно. Для поиска ошибок можно использовать средства отладки.

Алгоритмическая конструкция «следование»

📌 Определение Алгоритмическая конструкция «следование» — это последовательность команд алгоритма, которые выполняются в том порядке, в котором они записаны. Среди команд, образующих алгоритмическую конструкцию «следование», отсутствуют команды, меняющие порядок выполнения других команд.

В 7-м классе, решая задачи на языке Python, вы использовали следующие команды:

  • команду для ввода данных;
  • команду для вывода данных;
  • оператор присваивания.

Для ввода данных предназначена команда input(). В скобках можно написать текст, поясняющий, что ввести.

Для вывода данных используют команду print(). Она позволяет выводить текстовые сообщения и числовые значения. Текстовые сообщения записываются в кавычках.

📌 Определение Оператор присваивания предназначен для того, чтобы задавать значения переменным или вычислять значение выражения (результат будет записан как значение переменной).

Формат записи оператора присваивания: <имя переменной> = <выражение>.

При вычислениях часто используются различные математические функции. Эти функции реализованы как встроенные вспомогательные алгоритмы и могут применяться при записи арифметических выражений. Для применения этих функций в программе нужно подключить библиотеку math.

ФункцияОписание
fabs(x)Находит модуль рационального числа x
pow(x, y)Находит значение xy
sqrt(x)Находит корень квадратный из числа x

Вспомогательные алгоритмы

Нередко в одной программе приходится выполнять одну и ту же последовательность команд несколько раз. В этом случае удобно использовать вспомогательный алгоритм, который можно выполнять нужное число раз, обращаясь к его названию.

📌 Определение Вспомогательный алгоритм — это алгоритм, который можно использовать в других алгоритмах, указав его имя и, если необходимо, значения аргументов.

Вспомогательный алгоритм решает некоторую часть основной задачи. Вызов вспомогательного алгоритма является командой, которая может заменить несколько команд.

Главное

  • Алгоритм — конечная последовательность точных действий, формальное выполнение которых позволяет получить решение задачи.
  • Исполнитель — человек или устройство, способное правильно выполнять команды алгоритмов.
  • Программа — алгоритм, записанный на языке программирования.
  • Три базовые алгоритмические конструкции: следование, повторение, ветвление.
  • Для ввода данных используется команда input(), для вывода — print().
  • Вспомогательный алгоритм — алгоритм, который можно использовать в других алгоритмах, указав его имя.
